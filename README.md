# tiny-stack-vm

A tiny stack virtual machine for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty. One compact TypeScript program (`main.ts`) runs every instance of the set: it executes the bytecode program, answers with exactly the bytes it writes and the exit code it ends with.
